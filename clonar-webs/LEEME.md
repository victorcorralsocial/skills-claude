# Clonador de webs (plantilla para Claude Code)

Esta carpeta es la plantilla **AI Website Cloner Template** de JCodesMore, sin cambios
(https://github.com/JCodesMore/ai-website-cloner-template, versión del 10-11-2026, licencia MIT: archivo LICENSE).
Lo único añadido es este LEEME.

## Cómo se usa (resumen; la guía lo cuenta paso a paso)
1. Descomprime el zip donde quieras (por ejemplo, en tu carpeta de usuario).
2. Abre Claude Code **dentro de la carpeta `clonador-webs`** y pégale el mensaje de montarlo de la guía
   (instala lo que necesita con `npm install` y comprueba que todo va con `npm run check`).
3. Escribe `/clone-website https://la-web-que-quieras.com`.

Hace falta Claude Code (plan de pago de Claude) y Node.js 24 o más nuevo (gratis en nodejs.org).
La web copiada se queda en tu ordenador: no se publica nada. Lo de la web original (logo, textos, fotos)
es de su dueño: úsala para aprender o como base que luego cambias entera por lo tuyo.

Guía de Víctor Corral (vídeo «Claude ya puede copiar cualquier web»).
