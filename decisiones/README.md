# Decisiones: 3 skills para decidir mejor con Claude

Adaptación al español de tres skills de [Matt Pocock](https://github.com/mattpocock/skills) (licencia MIT, en cada carpeta):

- **grill-me**: te interroga por rondas antes de una decisión, con su respuesta recomendada en cada pregunta (junta `grill-me` y `grilling` del original).
- **wait-what**: te vuelve a explicar lo último en lenguaje sencillo.
- **to-questionnaire**: te prepara un cuestionario para la persona que sabe lo que tú no (el banco, el gestor…).

Cambios respecto al original: traducidas, sin `disable-model-invocation` (en la app de Claude no hay comandos y Claude no las vería) y con descripciones que dicen cuándo usarlas. Son solo texto: sin código ni conexiones.

Guía de Víctor Corral con cómo instalarlas y ejemplos para probarlas.
